# Squircle icon sources — Stage 1 note

#

# `original/` holds the editable, human-authored SVG sources for Squircle's

# custom-drawn icon set (MIT, original work). These files are the source of

# truth and are committed to version control.

#

# Optimized and generated assets (SVGO output, symbol sprites, per-icon

# files) are build artifacts and are written to `packages/icons/dist/` —

# they are never stored alongside the sources.

#

# The custom icon set itself is drawn in Stage 5. This directory structure

# exists from Stage 1 so the separation is enforced before any icon exists.
